# Modèle de fiche du registre des traitements — Vidéosurveillance avec Flux

*Fiche à recopier dans le registre RGPD (article 30) du client et dans le registre des activités de traitement d'images de la loi caméras. Adaptez les passages entre crochets.*

| Rubrique | Contenu |
|---|---|
| **Responsable du traitement** | [Nom de l'entreprise], [adresse], [n° BCE], contact : [mail, téléphone] |
| **Délégué à la protection des données** | [Nom ou « non désigné »] |
| **Nom du traitement** | Vidéosurveillance du [magasin / site] avec analyse automatique (logiciel Flux) |
| **Finalités** | Prévenir, constater et dissuader les vols, agressions, dégradations et incivilités ; identifier les auteurs ; sécurité des personnes et des biens. [Si utilisé : comptage anonyme de la fréquentation.] |
| **Base légale** | Intérêt légitime (art. 6.1.f RGPD), dans le cadre de la loi du 21 mars 2007. [Si reconnaissance des visages : base de l'art. 9.2 RGPD à justifier, voir AIPD.] |
| **Personnes concernées** | Clients, visiteurs, fournisseurs, personnel, [autres] |
| **Données** | Images ; journal des détections (heure, caméra, type d'événement) ; photos d'alerte ; [plaques d'immatriculation] ; [gabarits de visages des personnes en liste noire] ; comptes des utilisateurs de FluxLite, Flux Remote et web |
| **Lieux filmés** | [Liste des caméras et de ce qu'elles filment, ex. « Entrée, caisses, réserve, parking »] |

| **Transferts hors UE** | Aucun (images et données sur le PC Flux du site) |
| **Durées de conservation** | Vidéos : [≤ 30] jours ; alertes et photos dans les applications : [7] jours ; journal des actions : [≤ 30] jours ; base des personnes : [durée] ; images servant de preuve : jusqu'à la fin de la procédure |
| **Mesures de sécurité** | PC Flux dans un local fermé, session protégée ; accès aux applications par compte personnel, mots de passe hachés (scrypt), sessions révocables ; chiffrement TLS avec clé épinglée ; accès hors site par relais chiffré de bout en bout ; droits par entreprise et par caméra ; journal des commandes avec le nom de l'auteur ; floutage des visages [activé / non] ; mises à jour vérifiées (SHA-256) |

| **Date de la fiche** | [date], mise à jour le [date] |
