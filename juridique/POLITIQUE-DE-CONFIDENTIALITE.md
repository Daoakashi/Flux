# Politique de confidentialité de DMS Security

*Version 1.0 du [À COMPLÉTER : date].*

Cette politique concerne les données que **DMS Security**, éditeur de Flux, traite lui-même.

Les images des caméras, les comptes des utilisateurs et le journal des alertes **ne sont pas** traités par DMS Security : ils restent sur le PC Flux de chaque client, qui en est le responsable du traitement. Pour ces données, adressez-vous à l'entreprise qui exploite les caméras. Son nom est affiché dans les applications.

## Responsable

DMS Security, [adresse À COMPLÉTER], dms.security.list@gmail.com.

## Données traitées

| Quoi | D'où | Pourquoi | Base légale | Durée |
|---|---|---|---|---|
| Messages de **Feedback** : adresse mail, contenu, version du programme et du système | Bouton Feedback (mail) | Répondre, corriger les problèmes, améliorer les programmes | Intérêt légitime | 3 ans après le dernier échange |
| Tickets **GitHub** | Bouton Feedback (GitHub) | Idem, de façon publique | Intérêt légitime | Tant que le ticket existe ; publié par GitHub selon sa propre politique |
| Clients et prospects : nom, société, coordonnées, factures | Contrats, devis | Exécution du contrat, comptabilité | Contrat, obligation légale | Durée du contrat + 7 ans (obligations comptables belges) |
| **Relais Flux** : adresse IP de connexion, clé publique du PC Flux, nombre de connexions, horaires | Connexions au relais | Acheminer les connexions, protéger le service contre les abus | Intérêt légitime, contrat | En mémoire pendant la connexion ; journal technique de 7 jours au plus |
| **Mises à jour** : adresse IP | Vérification des mises à jour, hébergée par GitHub | Proposer les nouvelles versions | Intérêt légitime | Traitée par GitHub ; DMS Security n'y a pas accès |

Le relais **ne peut pas lire** le contenu qu'il transporte : les images, les mots de passe et les alertes sont chiffrés de bout en bout entre l'application et le PC Flux.

Les programmes n'envoient **aucune** statistique d'utilisation, aucune image et aucune donnée de caméra à DMS Security ni à un service d'intelligence artificielle.

## Destinataires et transferts

- GitHub, Inc. (États-Unis) : hébergement du code, du site et des téléchargements. Transferts encadrés par le cadre de protection des données UE–États-Unis (Data Privacy Framework) auquel GitHub adhère.
- Fournisseur de messagerie (Google, Gmail) pour les mails de Feedback.
- Hébergeur du relais : [À COMPLÉTER, par exemple « serveur de DMS Security en Belgique » ou nom de l'hébergeur].
- Comptable et autorités, lorsque la loi l'impose.

## Vos droits

Vous pouvez demander l'accès, la rectification, l'effacement, la limitation, la portabilité de vos données, ou vous opposer à leur traitement, en écrivant à dms.security.list@gmail.com. Vous pouvez introduire une plainte auprès de l'Autorité de protection des données : https://www.autoriteprotectiondonnees.be (ou la CNIL en France).
