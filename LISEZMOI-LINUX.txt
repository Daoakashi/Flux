FLUX 0.7.0 alpha — Surveillance vidéo intelligente
Dépôt officiel et mises à jour : https://github.com/Daoakashi/Flux
==================================================

INSTALLATION (Linux Mint, Ubuntu, Debian)
-----------------------------------------
1) Décompressez l'archive dans un dossier à vous (clic droit › Extraire ici), par exemple dans
   Documents. Évitez un disque USB formaté en NTFS ou exFAT.
2) Ouvrez un terminal dans ce dossier (clic droit dans le dossier › « Ouvrir dans un terminal »)
   et tapez :
        bash installer.sh
   (ou double-clic sur installer.sh › « Exécuter dans un terminal »).
   Le mot de passe de votre session est demandé une fois pour installer les paquets du système.
   Le script s'occupe de tout :
     - paquets du système : Python, ffmpeg, bibliothèques graphiques de Qt
     - l'environnement « venv » dans ce dossier
     - PyTorch pour processeur (léger, environ 200 Mo) ou avec CUDA si une carte NVIDIA est présente
     - toutes les dépendances, yt-dlp à jour, OpenCV réglé pour Linux
     - Deno (YouTube) et le modèle de détection YOLO26n
     - une vérification, l'icône « Flux » dans le menu et sur le bureau
     - en option (il pose la question) : démarrage automatique de Flux à l'ouverture de session et
       mise en veille désactivée, utiles pour une surveillance 24 h/24
   Comptez 10 à 20 minutes selon la connexion. installer.sh peut être relancé à tout moment : il
   répare et met à jour sans tout réinstaller.
3) Lancez Flux avec l'icône du bureau, depuis le menu des applications (Son et vidéo), ou ./Flux.sh.
   Si l'icône du bureau est grise : clic droit › « Autoriser le lancement ».

MINI-PC SANS CARTE GRAPHIQUE (exemple : Minisforum GK41, Celeron J4125, 4 cœurs)
-------------------------------------------------------------------------------
Flux fonctionne sur processeur, mais ce petit processeur est limité :
  - Au premier lancement, Flux choisit seul des réglages légers : niveau Rapide (YOLO26n), une image
    analysée sur 2, animations coupées, vidéos de passage plus légères.
  - Le moteur OpenVINO est utilisé automatiquement (converti pendant installer.sh) : environ 1,5 à 3 fois
    plus rapide que PyTorch sur ce type de processeur. L'analyse se met en veille quand rien ne bouge.
    Essayez aussi Réglages › Détection › Processeur de calcul › « Puce graphique Intel » (paquet
    intel-opencl-icd nécessaire : sudo apt install intel-opencl-icd).
  - Dessinez des zones sur les parties utiles de l'image : l'analyse se concentre dessus.
  - Comptez 2 à 4 caméras en analyse. Gardez le niveau Rapide ; Équilibré ralentit beaucoup, Précis et
    Maximum sont inutilisables sans carte graphique.
  - Pour beaucoup de caméras, utilisez le flux secondaire (basse résolution) de vos caméras IP : c'est
    le réglage qui change le plus les performances. Réglages › Détection › « Analyser une image sur »
    permet d'alléger encore.
  - Les groupes de caméras (mur vidéo) sont peu coûteux : seule l'analyse pèse sur le processeur.
  - 8 Go de mémoire conviennent ; en dessous de 4 Go, limitez-vous à 1 ou 2 caméras.
  - Le niveau « Basse lumière » est gourmand : coupez-le (Réglages › Basse lumière) si l'image
    saccade et que vos caméras ont déjà un mode infrarouge.
  - Branchez l'ordinateur en Ethernet plutôt qu'en Wi-Fi pour les caméras réseau.
Si installer.sh annonce que le processeur ne gère pas une instruction (AVX), notez le modèle de
processeur affiché et demandez une version adaptée.

MISE À JOUR DEPUIS UNE VERSION PRÉCÉDENTE
  Copiez le contenu de cette archive par-dessus votre dossier Flux actuel (acceptez de remplacer).
  config.json, flux.db, modeles et venv sont conservés. Relancez ensuite « bash installer.sh » une
  fois. Ensuite, les mises à jour se font depuis Flux (voir PERFORMANCES (Réglages › Détection)
-----------------------------------
  - Moteur d'analyse « Automatique » : PyTorch sur carte NVIDIA (demi-précision), OpenVINO sur
    processeur Intel ou AMD (1,5 à 3 fois plus rapide). La conversion du modèle se fait une seule fois
    (pendant l'installation ou au premier démarrage d'une caméra), puis elle est gardée dans « modeles ».
  - « Puce graphique Intel » (Processeur de calcul) : utilise la puce graphique intégrée des PC Intel
    avec OpenVINO. Essayez-la sur un mini-PC ; revenez à « Automatique » si c'est plus lent.
  - « Analyser seulement quand ça bouge » : sans personne à l'image et sans mouvement, l'analyse se met en
    veille (vérification toutes les 2 s) et reprend au premier mouvement. Le sous-titre de la caméra
    affiche « analyse en veille ».
  - Avec des zones, l'analyse porte seulement sur le rectangle qui les entoure (plus rapide, plus précis).
  - Le moteur utilisé est indiqué dans la barre d'état et sous le nom de chaque caméra.

MISES À JOUR PAR GITHUB
-----------------------
Le dépôt officiel est déjà réglé : https://github.com/Daoakashi/Flux (Réglages › Mises à jour, champ
vide = ce dépôt). Flux vérifie au démarrage et propose l'installation : le code actuel est d'abord
sauvegardé dans « sauvegardes », puis seul le code est remplacé (réglages, base, modèles et venv
conservés). Si requirements.txt change, Flux demande de relancer installer.sh.
Pour publier une version : mode développeur › augmentez la version (version.json) ›
« Préparer une publication » › sur GitHub, Releases › Draft a new release, tag v0.7.0-alpha (cochez
« Set as a pre-release » pour alpha et beta). Inutile de joindre un zip : Flux télécharge le code de
la release. Le tag doit correspondre à version.json (0.7.0 + alpha = v0.7.0-alpha).
Sans release, Flux compare aussi le version.json de la branche principale.

MODE DÉVELOPPEUR
----------------
Activation : 7 clics sur la version dans « À propos » (ou Réglages › Système, réglages avancés).
Réglages › Développeur : nom de l'application, sous-titre, version affichée (ex. « Beta Version
0.3 alpha »), titre de la fenêtre, logo personnalisé, badge DEV, durée de l'écran de démarrage,
édition de version.json, éditeur de config.json avec vérification avant d'appliquer, et
préparation d'une archive de publication.

DONNÉES PERSONNELLES
--------------------
Visages, expressions et plaques sont des données personnelles ; la reconnaissance faciale relève
des données biométriques (RGPD, article 9). Informez les personnes filmées, limitez la durée de
conservation (Réglages › Base de données) et ne filmez pas au-delà de votre propriété.
Flux fonctionne entièrement en local : aucune image ne quitte votre ordinateur, hors mails et
notifications que vous configurez (une photo envoyée par Telegram, ntfy ou Discord transite par
ces services). La vérification des mises à jour ne lit que la liste des versions sur GitHub.
L'envoi de statistiques d'Ultralytics est désactivé.

Licences des modèles : YOLO26/YOLO11/RT-DETR (Ultralytics, AGPL-3.0), YuNet et SFace (OpenCV Zoo),
HSEmotion, RapidOCR. Pour un usage commercial, vérifiez la licence Ultralytics.
