FLUX 0.3.2 alpha — Surveillance vidéo intelligente
==================================================

INSTALLATION (Windows)
----------------------
1) Décompressez l'archive dans un dossier à vous (pas dans l'ancien dossier « yolp »).
2) Double-cliquez sur installer.bat. Il s'occupe de tout :
     - Python 3.12 (installé si absent ; relancez alors installer.bat une seconde fois)
     - l'environnement « venv » dans ce dossier
     - PyTorch avec CUDA si une carte NVIDIA est présente (plusieurs Go)
     - toutes les dépendances, yt-dlp à jour, OpenCV maintenu en version 4
     - Deno (YouTube) et ffmpeg (vidéos téléchargées avec le son), via winget
     - une vérification finale et un raccourci « Flux » sur le bureau
   installer.bat peut être relancé à tout moment : il répare et met à jour sans tout réinstaller.
3) Lancez Flux avec le raccourci du bureau ou Flux.bat.

MISE À JOUR DEPUIS UNE VERSION PRÉCÉDENTE
  Copiez le contenu de cette archive par-dessus votre dossier Flux actuel (acceptez de remplacer).
  config.json, flux.db, modeles et venv sont conservés. Pas de nouvelle dépendance : inutile de
  relancer installer.bat. La base est mise à niveau automatiquement au premier démarrage.
  Ensuite, les mises à jour se font depuis Flux (voir MISES À JOUR PAR GITHUB).

Si Flux ne démarre pas, une fenêtre explique l'erreur et le détail est écrit dans flux_erreur.log.

Installation manuelle (avancé) : créez un venv Python 3.10–3.13, installez PyTorch avec CUDA depuis
https://pytorch.org/get-started/locally/, puis « pip install -r requirements.txt » et « python flux.py ».

NIVEAUX DE SCAN
---------------
  Rapide     YOLO26n  · 640 px                 temps réel partout, même sans carte graphique
  Équilibré  YOLO26s  · 640 px                 bon compromis pour plusieurs caméras
  Précis     YOLO26x  · 960 px                 cibles lointaines, basse lumière
  Maximum    RT-DETR-X · 640 px + découpage 2×2 le plus précis, surtout dans le noir (carte requise)
  Personnalisé : n'importe quel modèle Ultralytics (yolo11x.pt, rtdetr-l.pt…) ou votre propre
  fichier .pt / .onnx / .engine (Réglages › Détection).
Chaque caméra peut avoir son propre niveau.

BASSE LUMIÈRE
-------------
Activée automatiquement quand l'image est sombre : éclaircissement, débruitage et contraste local,
puis « double passe » (image d'origine + image améliorée) pour ne jamais faire moins bien.
Dans le noir quasi total, seul le niveau Maximum reste fiable ; une caméra infrarouge reste la
meilleure solution.

FONCTIONS
---------
- Caméras : webcam, RTSP/HTTP, fichiers, liens web (YouTube en direct…), caméras ONVIF
  (recherche automatique sur le réseau, connexion et choix du profil vidéo).
- Visages : détection (YuNet), reconnaissance (SFace), expressions (HSEmotion).
  Les visages inconnus deviennent « Inconnu 1, 2… » ; renommez-les dans la page Personnes,
  fusionnez les doublons, ajoutez des photos. Catégories : connue, inconnue, surveillée,
  liste noire.
- Base de données (flux.db) : chaque personne, ses visages et ses actions (apparition,
  identification, entrée/sortie de zone, immobilité prolongée, départ avec durée).
- Plaques : détection des véhicules, localisation et lecture des plaques. Déposez un modèle
  YOLO spécialisé nommé « plaques.pt » à côté de flux.py pour une détection plus fiable.
- Lecteur : YouTube, Instagram, TikTok, Vimeo, fichiers… avec le son et l'analyse en direct.
  Instagram et les vidéos privées : Réglages › Lecteur vidéo › Cookies du navigateur.
  YouTube exige un moteur JavaScript : installez Deno (winget install DenoLand.Deno),
  puis gardez yt-dlp à jour : pip install -U "yt-dlp[default]" (YouTube change souvent).
  Mode « Télécharger puis lire » en meilleure qualité : installez ffmpeg (winget install ffmpeg).
- Alertes : notification, photo, mail (délai anti-spam), journal par mail.
- Journal : actions réparties en catégories (Liste noire, Alertes, Personnes surveillées,
  Identifications, Passages, Zone et stationnement, Véhicules et plaques). Bouton « Catégories… »
  pour en créer, changer les couleurs, l'ordre et les règles (type d'action, catégorie de la
  personne, caméra, mots-clés). Clic droit sur une action : « Classer dans… » à la main.
- Réglages : tous les paramètres, recherche, thème clair ou sombre, couleur, police, taille,
  arrondis, densité, animations, opacité ; import et export.

LISTE NOIRE
-----------
Personnes : page Personnes › catégorie « Liste noire ». Plaques : Réglages › Plaques › Plaques en
liste noire (ex. 1-ABC-234, la caméra doit avoir « Lire les plaques »). Une détection en liste
noire déclenche toujours une alerte prioritaire : mail et notifications envoyés immédiatement,
sans tenir compte du délai anti-spam, et classée dans la catégorie « Liste noire » du journal.

NOTIFICATIONS SUR LE TÉLÉPHONE (Réglages › Notifications)
--------------------------------------------------------
Activez « Envoyer des notifications », puis un ou plusieurs canaux. Chaque canal a un bouton
« Tester ». Rien à installer sur le PC.
  ntfy (le plus simple, gratuit, sans compte) : installez l'application ntfy sur le téléphone,
     abonnez-vous à un sujet difficile à deviner (ex. flux-maison-7f3k9q), saisissez-le dans Flux.
  Telegram (gratuit, avec photo) : sur Telegram, écrivez à @BotFather › /newbot, copiez le jeton
     dans Flux, envoyez « bonjour » à votre bot, puis « Trouver mon identifiant Telegram ».
  WhatsApp gratuit (CallMeBot, texte seul, votre propre numéro) : envoyez « I allow callmebot to
     send me messages » au +34 644 66 32 62 sur WhatsApp ; vous recevez une clé à saisir dans Flux.
  WhatsApp officiel, SMS et appel téléphonique : compte Twilio (payant). L'appel lit l'alerte à
     voix haute ; par défaut il est réservé à la liste noire.
  Discord : webhook d'un salon. Webhook générique (avancé) : JSON pour Home Assistant, n8n…
Les catégories du journal marquées « Notifier » envoient aussi leurs actions.
Les jetons et clés sont enregistrés dans config.json : ne partagez pas ce fichier (l'export des
réglages, lui, les retire).

MISES À JOUR PAR GITHUB
-----------------------
Réglages › Mises à jour : indiquez le dépôt (propriétaire/dépôt). Flux vérifie au démarrage et
propose l'installation : le code actuel est d'abord sauvegardé dans « sauvegardes », puis seul le
code est remplacé (réglages, base, modèles et venv conservés). Si requirements.txt change, Flux
demande de relancer installer.bat.
Pour publier une version : mode développeur › augmentez la version (version.json) ›
« Préparer une publication » › sur GitHub, Releases › Draft a new release, tag v0.3.1 (cochez
« Set as a pre-release » pour alpha et beta), joignez le zip du dossier « publication ».
Sans release, Flux compare aussi le version.json de la branche principale.

MODE DÉVELOPPEUR
----------------
Activation : 7 clics sur la version dans « À propos » (ou Réglages › Système, réglages avancés).
Réglages › Développeur : nom de l'application, sous-titre, version affichée (ex. « Beta Version
0.3 alpha »), titre de la fenêtre, logo personnalisé, badge DEV, durée de l'écran de démarrage,
édition de version.json, éditeur de config.json avec vérification avant d'appliquer, et
préparation d'une archive de publication.

DONNÉES PERSONNELLES
--------------------
Visages, expressions et plaques sont des données personnelles ; la reconnaissance faciale relève
des données biométriques (RGPD, article 9). Informez les personnes filmées, limitez la durée de
conservation (Réglages › Base de données) et ne filmez pas au-delà de votre propriété.
Flux fonctionne entièrement en local : aucune image ne quitte votre ordinateur, hors mails et
notifications que vous configurez (une photo envoyée par Telegram, ntfy ou Discord transite par
ces services). La vérification des mises à jour ne lit que la liste des versions sur GitHub.
L'envoi de statistiques d'Ultralytics est désactivé.

HSEmotion, RapidOCR. Pour un usage commercial, vérifiez la licence Ultralytics.
